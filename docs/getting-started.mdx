# Getting started

Replot is a React component library: charts are built with declarative JSX via the [React component API](#plot-in-react).

## Installing from npm

If you’re developing a web application using Node, you can install Replot via yarn, npm, pnpm, or your preferred package manager. Replot is published under the scoped name `@dave-hillier/replot`, because the bare name `replot` belongs to an unrelated package on npm. While the API is still settling, releases are prereleases published under the `next` dist-tag, so add `@next` to the install commands below until 0.1.0 is out.


```bash [yarn]
yarn add @dave-hillier/replot
```

```bash [npm]
npm install @dave-hillier/replot
```

```bash [pnpm]
pnpm add @dave-hillier/replot
```

You can then import Replot's components from `@dave-hillier/replot/react`:

```js
import {Replot, Dot, Line, BarY, AxisX, AxisY} from "@dave-hillier/replot/react";
```

Replot includes TypeScript declarations with extensive documentation. We highly recommend using an editor with enhanced code completion such as Visual Studio Code or Observable.

## Replot in React {/* {#plot-in-react} */}

Replot provides a first-class React component API via `@dave-hillier/replot/react`. Instead of imperatively building SVG with D3 selections, you define charts declaratively with JSX that integrates natively with React's rendering model, state management, and component lifecycle.

### Basic usage

Import the `Replot` root component and mark components, then compose them as JSX:

```jsx [App.jsx]
import {Replot, Dot, AxisX, AxisY} from "@dave-hillier/replot/react";
import penguins from "./penguins.json";

export default function App() {
  return (
    <div>
      <h1>Penguins</h1>
      <Replot width={640} height={400}>
        <Dot data={penguins} x="culmen_length_mm" y="culmen_depth_mm" fill="species" />
        <AxisX />
        <AxisY />
      </Replot>
    </div>
  );
}
```
The `<Replot>` component handles scale inference, axis generation, and layout automatically. Pass scale options as props on `<Replot>`, and channel mappings as props on mark components. Every mark in the grammar is a React component: `<Dot>`, `<Line>`, `<BarX>`, `<BarY>`, `<Area>`, `<Rect>`, `<Text>`, `<Rule>`, `<Tick>`, and [many more](./api.md).

### With transforms

Transforms such as binning, grouping, and stacking are available as wrapper components: nest a mark inside the wrapper, with the transform options as props on the wrapper and the input channels on the mark.

```jsx [Histogram.jsx]
import {Replot, BarY, RuleY, BinX} from "@dave-hillier/replot/react";

export default function Histogram({data}) {
  return (
    <Replot>
      <BinX y="count">
        <BarY data={data} x="value" fill="steelblue" />
      </BinX>
      <RuleY data={[0]} />
    </Replot>
  );
}
```

Transforms are also available as pure functions (`binX`, `groupX`, `stackY`, …) whose result you can spread onto a mark: `<BarY data={data} {...binX({y: "count"}, {x: "value"})} />`.
### With scale options

Configure scales by passing options directly to `<Replot>`:

```jsx [TemperatureChart.jsx]
import {Replot, Dot, RuleY} from "@dave-hillier/replot/react";

export default function TemperatureChart({data}) {
  return (
    <Replot y={{grid: true}} color={{scheme: "burd"}}>
      <RuleY data={[0]} />
      <Dot data={data} x="Date" y="Anomaly" stroke="Anomaly" />
    </Replot>
  );
}
```
### With facets

Use the `fx` or `fy` props on mark components to create small multiples:

```jsx [FacetedChart.jsx]
import {Replot, Dot} from "@dave-hillier/replot/react";

export default function FacetedChart({data}) {
  return (
    <Replot>
      <Dot data={data} x="culmen_length_mm" y="culmen_depth_mm" fx="species" />
    </Replot>
  );
}
```
### With tooltips

Add interactive tooltips with the `tip` prop on any mark, or use the `<Tip>` component for more control:

```jsx [InteractiveChart.jsx]
import {Replot, Dot} from "@dave-hillier/replot/react";

export default function InteractiveChart({data}) {
  return (
    <Replot>
      <Dot data={data} x="weight" y="height" fill="species" tip />
    </Replot>
  );
}
```
### With legends

Use the `<Legend>` component to add a legend for any scale:

```jsx [LegendChart.jsx]
import {Replot, Dot, Legend} from "@dave-hillier/replot/react";

export default function LegendChart({data}) {
  return (
    <Replot color={{legend: true}}>
      <Dot data={data} x="weight" y="height" fill="species" />
    </Replot>
  );
}
```
### Figure wrapping

Use the `title`, `subtitle`, and `caption` props on `<Replot>` to wrap the chart in a `<figure>` element:

```jsx [FigureChart.jsx]
import {Replot, Line} from "@dave-hillier/replot/react";

export default function FigureChart({data}) {
  return (
    <Replot title="Temperature over time" subtitle="Global average" caption="Source: NASA">
      <Line data={data} x="date" y="temperature" />
    </Replot>
  );
}
```
### Async data loading

Combine React's `useState` and `useEffect` with Replot components:

```jsx [AsyncChart.jsx]
import {Replot, Dot, RuleY} from "@dave-hillier/replot/react";
import * as d3 from "d3";
import {useEffect, useState} from "react";

export default function AsyncChart() {
  const [data, setData] = useState();

  useEffect(() => {
    d3.csv("/gistemp.csv", d3.autoType).then(setData);
  }, []);

  if (!data) return <p>Loading…</p>;

  return (
    <Replot y={{grid: true}} color={{scheme: "burd"}}>
      <RuleY data={[0]} />
      <Dot data={data} x="Date" y="Anomaly" stroke="Anomaly" />
    </Replot>
  );
}
```

Replot shares its computational core with [Observable Plot](https://observablehq.com/plot/), whose documentation remains a good companion for the underlying grammar of marks, scales, and transforms.

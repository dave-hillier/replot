# Replot

**Replot** is a React component library for exploratory data visualization. It brings the *grammar of graphics* — layered marks, scales, and transforms, in the style of [Observable Plot](https://observablehq.com/plot/) — to idiomatic, declarative JSX.

export const sales = [
  {date: new Date("2024-01-01"), fruit: "apples", units: 32},
  {date: new Date("2024-01-01"), fruit: "oranges", units: 18},
  {date: new Date("2024-02-01"), fruit: "apples", units: 41},
  {date: new Date("2024-02-01"), fruit: "oranges", units: 27},
  {date: new Date("2024-03-01"), fruit: "apples", units: 35},
  {date: new Date("2024-03-01"), fruit: "oranges", units: 39},
  {date: new Date("2024-04-01"), fruit: "apples", units: 48},
  {date: new Date("2024-04-01"), fruit: "oranges", units: 44},
  {date: new Date("2024-05-01"), fruit: "apples", units: 44},
  {date: new Date("2024-05-01"), fruit: "oranges", units: 57}
];

<Replot color={{legend: true}}>
  <StackY>
    <AreaY data={sales} x="date" y="units" fill="fruit" />
  </StackY>
  <RuleY data={[0]} />
</Replot>

Marks are components, layered as siblings. Transforms are components too — they nest, mirroring the grammar's functional composition:

<Replot>
  <BinX y="count">
    <RectY data={useOlympians()} x="weight" fill="sex" />
  </BinX>
  <RuleY data={[0]} />
</Replot>

Everything participates in the React tree: state, context, Suspense, and server rendering work as you'd expect, with no manual DOM management. `renderToString` returns the whole plot, and a hydrating client redraws it once the marks have registered.
